
# Module 06: User Interface Design

## Learning Objectives
- Apply user-centered design (UCD) principles.
- Design interfaces following Golden Rules and usability heuristics.
- Create low-fidelity and high-fidelity prototypes.
- Conduct usability evaluation (e.g., heuristic evaluation, user testing).

## Key Topics

### 1. User-Centered Design (UCD)
- **Principles**: Early focus on users, empirical measurement, iterative design.
- **ISO 9241-210** standard for human-centered design.

### 2. Interface Design Process
- **User analysis**: Personas, scenarios, tasks.
- **Information architecture**: Navigation, labeling, search.
- **Wireframing & Prototyping**: Paper, digital (Figma, Balsamiq).
- **Evaluation**: Iterate based on feedback.

### 3. Golden Rules of UI Design (Shneiderman)
1. Strive for consistency.
2. Enable shortcuts for frequent users.
3. Offer informative feedback.
4. Design dialogs to yield closure.
5. Prevent errors & simple error handling.
6. Permit easy reversal of actions.
7. Support internal locus of control.
8. Reduce short-term memory load.

### 4. Nielsen’s 10 Usability Heuristics
- Visibility of system status.
- Match between system & real world.
- User control & freedom.
- Consistency & standards.
- Error prevention.
- Recognition rather than recall.
- Flexibility & efficiency of use.
- Aesthetic & minimalist design.
- Help users recognize & recover from errors.
- Help & documentation.

### 5. UI Design Patterns & Accessibility
- Common patterns: Login form, search results, breadcrumbs.
- **Web Content Accessibility Guidelines (WCAG)** 2.1:
  - Perceivable, operable, understandable, robust.
- Tools: WAVE, axe, screen readers.

### 6. Evaluation Methods
- **Heuristic evaluation** (by experts).
- **Usability testing** (with users, think-aloud).
- **Questionnaires** (SUS, QUIS).

## Learning Activities
- Redesign a poorly designed app/webpage using UCD.
- Conduct a heuristic evaluation on a given interface.

## Assessment
- Prototype (Figma or paper) + usability test plan.
- Individual report: Usability evaluation of a chosen application.
