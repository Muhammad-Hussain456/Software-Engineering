
# Module 11: Software Metrics & Measurement

## Learning Objectives
- Classify metrics: product, process, project.
- Apply size-oriented (LOC) and function-oriented (FP) metrics.
- Use object-oriented metrics (CK suite).
- Interpret metrics for decision-making and process improvement.

## Key Topics

### 1. Fundamentals of Measurement
- **Measure, Metric, Indicator**.
- **Goal-Question-Metric (GQM)** approach:
  - Define goal → ask questions → identify metrics.
- **Classification**:
  - Product metrics (code, design, test).
  - Process metrics (development time, review efficiency).
  - Project metrics (cost, schedule, team size).

### 2. Size-Oriented Metrics
- **Lines of Code (LOC)**:
  - Advantages: Simple, automatable.
  - Disadvantages: Language-dependent, penalizes concise code.
  - Metrics: KLOC, defects/KLOC, cost/KLOC.

### 3. Function-Oriented Metrics (Function Points)
- **Albrecht’s Function Points**:
  - Count inputs, outputs, inquiries, internal files, external interfaces.
  - Complexity adjustment factor.
  - **Derived**: FP per person-month, defects/FP.
- **Use cases**: COCOMO II estimation, benchmarking.

### 4. Object-Oriented Metrics (CK Suite)
- **Chidamber & Kemerer (CK)**:
  - WMC (Weighted Methods per Class)
  - DIT (Depth of Inheritance Tree)
  - NOC (Number of Children)
  - CBO (Coupling Between Objects)
  - RFC (Response For a Class)
  - LCOM (Lack of Cohesion of Methods)

### 5. Complexity Metrics
- **McCabe’s Cyclomatic Complexity** = Edges − Nodes + 2P.
  - Indicates number of independent paths.
  - Guideline: Keep < 10 per function.
- **Halstead Metrics**: Vocabulary, length, volume, difficulty.

### 6. Process & Project Metrics
- **Earned Value Management (EVM)**: PV, EV, AC, SPI, CPI.
- **Defect removal efficiency** = defects found before release / (before + after).
- **Review metrics**: preparation rate, defect detection rate.

### 7. Using Metrics for Improvement
- **Baseline** → **Goal** → **Measure** → **Analyze** → **Act**.
- **Common pitfalls**:
  - Vanity metrics (look good, no action).
  - Goodhart’s law: “When a measure becomes a target, it ceases to be a good measure.”

## Learning Activities
- Compute function points for a given requirements document.
- Calculate CK metrics for a small Java/Python class hierarchy.

## Assessment
- Metrics report: Analyze a small system using LOC, FP, and CC.
- GQM exercise: Define 3 metrics for a specific improvement goal.
