
# Module 10: Software Quality Assurance (SQA)

## Learning Objectives
- Define SQA and distinguish from testing.
- Apply quality standards (ISO 25010, CMMI).
- Plan SQA activities across the software lifecycle.
- Use reviews, audits, and process metrics for quality improvement.

## Key Topics

### 1. What is SQA?
- **Definition**: Systematic activities to ensure software processes and products conform to requirements and standards.
- **SQA vs. Testing**:
  - Testing is *one* SQA activity (detection).
  - SQA includes prevention, process assurance, audits.

### 2. Quality Models & Standards
- **ISO/IEC 25010** (Quality Characteristics):
  - Functional suitability, reliability, performance efficiency, usability, security, compatibility, maintainability, portability.
- **CMMI** (Capability Maturity Model Integration):
  - Levels 1–5: Initial → Managed → Defined → Quantitatively Managed → Optimizing.
- **IEEE 730** SQA process standard.

### 3. SQA Activities
- **Process assurance**: Are we following defined processes?
- **Product assurance**: Reviews, inspections, testing.
- **Audits**: Formal evaluation of compliance.
- **SQA plan**: Defines responsibilities, activities, tools.

### 4. Reviews & Inspections
- **Fagan Inspection**: Planning → overview → preparation → inspection → rework → follow-up.
- **Walkthroughs** (less formal), **technical reviews**.
- **Checklists** for defect detection.

### 5. SQA Metrics & Measurement
- **Defect density**, **review effectiveness**, **process compliance %**.
- **Cost of Quality**:
  - Prevention costs (training, reviews).
  - Appraisal costs (testing, inspections).
  - Failure costs (internal/external defects).

### 6. Tools for SQA
- Static analysis (SonarQube, ESLint).
- Process management (Jira, Trello with compliance).
- Audit management.

## Learning Activities
- Conduct a Fagan inspection on a small code or requirements document.
- Create an SQA plan for a given project (2–3 pages).

## Assessment
- Inspection report (defects found, severity, rework).
- Quality audit checklist + findings.
