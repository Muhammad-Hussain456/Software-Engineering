# Software Engineering

## 🗺️ Course Outline 

#### Module 1: Introduction, Processes, Models & Professional Practice
**Covers:**  – Software Engineering Process, Models & Methods, Professional Practice, Engineering Foundations.

- 1.1 The Nature of Software (program vs. software, software crisis).
- 1.2 Software Process Models (Waterfall, Incremental, Spiral, Agile vs. Plan-Driven; Agile Manifesto, Scrum, XP).
- 1.3 Team Structures & Communication.
- 1.4 Professional Practice & Ethics (ACM/IEEE Code, responsibilities, societal impact).

> **💡 Study Activity:** Comparison chart: Waterfall vs. Agile (when to choose each).

---

#### Module 2: Requirements Engineering
**Covers:** Software Requirements.

- 2.1 Types of Requirements (functional, non-functional, quality-of-service, constraints).
- 2.2 Elicitation & Analysis (interviews, workshops, prototyping).
- 2.3 Documentation (User Stories, Use Cases, SRS).

> **💻 Hands-On:** 5 user stories + 1 detailed use case for the to-do list app.

---

#### Module 3: Software Project Management & Economics
**Covers:**   Software Engineering Management, Software Engineering Economics.

- 3.1 Planning & Estimation (WBS, COCOMO, planning poker, expert judgment).
- 3.2 Scheduling (Gantt, critical path).
- 3.3 Risk Management.
- 3.4 Economics (cost-benefit, make-vs-buy, technical debt costing).
- 3.5 Agile Metrics (velocity, burndown).

> **💡 Study Activity:** For the to-do list app project: list 5 risks, estimate effort, simple Gantt chart.

---
#### Module 4: System Modeling & Design
**Covers:** Software Design, Software Engineering Models & Methods.

- 4.1 UML (Class, Component, Deployment, Use Case, Sequence, Activity diagrams).
- 4.2 Design Principles (SOLID, GRASP).
- 4.3 Design Patterns (Singleton, Factory, Observer, Strategy, etc.).
- 4.4 Model-Driven Approaches.

> **💻 Hands-On:** UML Class + Sequence diagram for the “add task” use case.

---

#### Module 5: Software Construction & Implementation
**Covers:**   Software Architecture, Software Construction, Software Configuration Management.

- 5.1 Architectural Styles & Patterns (MVC, Layered, Client-Server, Microservices vs. Monolith, Event-Driven).
- 5.2 Architecture Description (views, viewpoints, decisions).
- 5.3 Evaluation & Tactics (trade-off analysis, quality attributes).
- 3.4 Implementation Best Practices (clean code, refactoring, standards).
- 3.5 Version Control & Config Management (Git advanced: branching strategies, pull requests, semantic versioning, trunk-based
  development; baselines, change control).
- 3.6 Build & Release Engineering basics.

> **💻 Hands-On:** Draw MVC + deployment architecture diagram for the to-do list app (include cloud option).

---

#### Module 6: Software Testing, Quality & Security
**Covers:**   Software Testing, Software Quality, Software Security.

- 6.1 Testing Levels & Techniques (unit, integration, system, acceptance; TDD, test doubles, coverage).
- 6.2 Quality Management (ISO 25010, reviews, static analysis, metrics).
- 6.3 Security Engineering (secure-by-design, OWASP Top 10, threat modeling, authentication, input validation, DevSecOps).

> **💻 Hands-On:** Write unit test (with mock) for a core function (e.g., `calculateTotal` or task validation) + add one security test (e.g., input sanitization).

---

#### Module 7: DevOps, Operations, Maintenance, Evolution 
**Covers:**   Software Engineering Operations, Software Maintenance, remaining Process/Quality integration + review.

- 7.1 DevOps & CI/CD (pipelines, Infrastructure as Code, automation).
- 7.2 Software Engineering Operations (deployment, monitoring, observability, incident management, rollback).
- 7.3 Maintenance & Evolution (corrective/adaptive/perfective, legacy systems, technical debt).
- 7.4 Emerging Trends (AI in SE, Cloud-Native, Containerization/Docker/K8s basics, observability).

> **💡 Study Activity:** Research CI/CD pipeline + technical debt. Explain their importance in a professional setting. (Optional extension: deploy your to-do list app to a free cloud service.)
